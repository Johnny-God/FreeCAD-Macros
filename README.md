# My FreeCAD Macros

Macros I use. Packaged addons live in their own repositories.

## Macros

- **[EasyAlias.FCMacro](EasyAlias.FCMacro)** — a vendored copy of the community
  [Macro EasyAlias](https://wiki.freecad.org/Macro_EasyAlias) by TheMarkster
  and rosta. Creates spreadsheet aliases from the values in the previous
  column.

## Moved

- **EasyStart** — the new-document bootstrapper now lives in its own
  repository: **[Johnny-God/EasyStart](https://github.com/Johnny-God/EasyStart)**.
